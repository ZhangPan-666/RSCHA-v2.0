# R-SCHA 数学手册全面复核与修订报告

日期：2026-11-06。复核基准为上一轮图件修订后的165页版本。

## 结论

**原稿不能认定为“完全客观、绝对正确且没有冗余”的数学手册。** 主体分离变量、径向谱、特殊函数和能量公式中有大量正确内容，但仍存在实质性的条件缺失、过强结论、函数空间表述问题、文献元信息错误和重复说明。部分问题可由明确反例否定，不能仅作为措辞偏好处理。

本次修订后的版本为160页。已修正下述已确认问题、补充必要证明和适用条件，并删减重复推导和无依据的研究状态断言。现有数值与结构检查通过；这支持已核对的公式与反例，**不构成全书任意参数、任意无限级数均无错误的证明**。

## 一、实质错误和缺少条件

### 1. R-SCHA2D 的圆边数据漏写观察半径

涉及源章节05（成书第12节）。补势的圆边导数条件原来只限定 `θ=θ0`，但随后给出的径向因子 `R2(r)` 并不恒定。若解释成对所有r施加相同圆边数据，公式与边界条件不相容。

已明确该数据施加于 `r=a, θ=θ0`，与一表面构造和后续公式一致。

### 2. “加上无穷远衰减即可消除不唯一”不成立

同一表面法向数据及其圆边北向数据，加上无穷远衰减，仍不足以唯一选定补势。对任意 `τ>0`，可取

```text
Rτ(r) = r^(−1/2)[cos(τ log r) + sin(τ log r)/(2τ)]   （取a=1）
```

此时 `Rτ′(1)=0` 且 `Rτ(r)→0`。配以正则Mehler角函数，并按圆边角导数归一化，不同τ可给出相同表面法向与圆边数据，却在内部有不同势值。测试中 `τ=0.7` 与 `τ=1.3` 在选定点的势值相差约2.24267。

现将 `n=−1/2` 分支表述为经典R-SCHA2D的选择，而非由上述不完整数据唯一推出。该方法的原始边界设置见 [Thébault 2008](https://academic.oup.com/gji/article/174/1/118/574974)。

### 3. “单半径数据必然不能区分两条径向支”过度概括

仅有法向数据时，每个实度n的模态只有

```text
z = −(n+1) gi + n ge
```

确实不能确定两个未知数。但若再有表面势系数 `c=gi+ge`，则矩阵行列式为 `2n+1>0`，两支可以恢复。精确完整的切向与法向场可提供Cauchy信息（势差一个规范常数）；唯一性和从有限、含噪观测延拓的稳定性必须分开。

已限定欠定断言适用于“只有一个半径的法向数据”，删除泛化。Neumann实度集合也补上 `n≥0`、角函数不得恒为零及重复度分支只计一次的条件。

### 4. 不等内外截断后，不能保证上下两面同时投影匹配

涉及第20、21节及总结。原稿允许内外Legendre序列分别截断，但又无条件声称有限模型同时再现两个球面的投影法向数据。这两种陈述不兼容。

反例：半球冠、`ra=1, rb=2`，目标势为 `r³ P3(cosθ)`。其两面向外法向系数是 `(-3,12)`。两支模态的边界矩阵为

```text
[ 4       −3 ]
[ −0.125  12 ]
```

配对解为内支0、外支1。删除所需外支后，不能靠保留的内支同时匹配两面。

现明确：两边界投影性质要求每个相关角模式的两条径向支均被保留。不对称截断仍可定义，但应视为完整展开的裁剪。

### 5. H¹体能量有限，不自动给出固定球面的有限梯度能量

涉及第17–19节及总结。`∇V∈L²(Ω)` 不蕴含每个固定球面上的 `∇V|Σβ∈L²(Σβ)`；边界半径尤其需要额外迹正则性。

解析反例可用单位球内调和级数

```text
V = Σ(n≥1) rⁿ Pn(cosθ)/n
```

其体Dirichlet能量为 `Σ 4π/[n(2n+1)]<∞`，但外球面势在北极附近为 `−logθ+O(1)`，切向梯度约为 `−1/θ`，所以任何包含该点的球冠上梯度平方积分发散。限制到 `ra<r<1` 的球冠壳仍具有有限H¹体能量。

现为固定球面能量明确加入L²梯度迹条件；无限展开的表面Gram公式要求相应部分和在表面梯度范数中收敛。有限模态公式继续有效。

### 6. 无限Gram矩阵和有限Gram矩阵不能不加区别

有限实基的Gram矩阵对称半正定是正确的。但无限矩阵不自动定义无权系数空间上的有界算子，必须声明二次型作用域。

系数核也不应无条件称为“一维”：准确说法是系数映射下常数势的原像。只有包含一个规范常数、其他模式独立时才是一维；冗余参数化可能产生额外核。连续全梯度唯一性也不提供随截断阶数一致的正下界。

这些区别已加入第18节。

### 7. L¹边界密度不足以直接调用弱解存在理论

原稿对边界积分的可定义性和有界弱Neumann泛函的条件混用。现将可直接使用的密度充分条件改为L²，并保留更一般的对偶迹空间表述。对Dirichlet数据则要求能由H¹函数提升，不能把任意L²侧边函数当作有限能量解的迹。

弱解唯一性用试探函数取自身证明；经典逐面Green积分只在相应边界正则性下使用。标准背景参考为 [McLean, *Strongly Elliptic Systems and Boundary Integral Equations*](https://assets.cambridge.org/97805216/63328/frontmatter/9780521663328_frontmatter.pdf)。

### 8. 分量L²完备不能直接跳到调和能量空间完备

第13节原有论述缺少提升到能量拓扑的环节。现补充：

- V1在角Dirichlet本征基展开，用角二次型和径向导数的Parseval恒等式表示能量；投影弱Laplace方程得到径向ODE，因此系数恰为两条Euler支。
- V2在径向Neumann和经度基展开，用径向二次型表示能量；弱方程给出角ODE，有限能量排除极点奇异支。
- 非负可求和的能量尾趋零，才推出相应能量收敛。

另用Lax–Milgram在整个调和H¹空间中构造分解，补齐原来依赖各子问题可解性的直和论证。该部分是解析证明，不是用数值样本代替证明。

### 9. 唯一投影函数不等于唯一系数向量

正交投影到有限维子空间的函数总是唯一；若选取的生成族线性相关，系数表示可以不唯一。独立性是系数唯一的条件，不是投影函数唯一的条件。

第21节已区分两者。同时说明非齐次本质边界条件的Galerkin离散必须使用提升；任意截断边界数据不自动等于原问题的Galerkin解。

### 10. 精确限制的单射性，不自动传递给有限投影后的矩阵

第20节现区分：唯一延拓支持精确函数限制的单射性；再投影为有限R-SCHA系数后，矩阵是否满列秩需单独检查。正则化是稳定估计的选择之一，不是所有精确有限系统数学唯一性的必要条件。

### 11. 全局H½法向迹与逐面的H½法向迹混淆

带边缘的球冠壳上，单位法向在不同面之间跳变。即使势全局光滑，也不能因此断言其标量法向导数属于整个边界上的H½。

反例：`u=z`，在 `θ0=π/3` 的内球面与侧面交边处，两个法向导数分别趋于 `−1/2` 和 `−√3/2`。跨边跳跃会破坏全局H½正则性。

现将H²所给的加强结论写成逐面H½空间；调和H¹收敛本来就给出的全局弱法向迹H⁻½收敛则单独列明。

### 12. 缩小角球冠不等于远离整个边界

只缩小角度范围仍可能碰到上下球面，不能直接套用与整个边界保持正距离的内部正则估计。第22节已改用真正紧包含于域内的子域。Poincaré控制也明确使用共同体积均值规范，避免暗示任意点值规范都适用于H¹。

### 13. 一些正确公式仍需明确分支和适用范围

- 球冠域改用笛卡尔集合定义，明确极轴在域内，避免把坐标奇点误作物理边界；符号表同步。
- Pochhammer符号补有限积定义，避免负整数参数时Gamma比出现形式0/0。
- Mehler归一化中 `τ=0` 的0/0商式与函数本身的有限极限分开；该极限仍不是非退化闭壳的正径向谱点。
- `A=O(θᵐ)` 单独不足以控制导数；补上正则ODE解的实际极点级数。
- 薄壳渐近明确对固定角度数成立，不宣称对无界度数一致。
- 非整数径向内/外支的命名不直接当作物理源区分离结论。
- 主动/被动旋转明确参照的基变换对象；分离常数改用Λ，避免与经度λ混用。

特殊函数约定以 [NIST DLMF第14章](https://dlmf.nist.gov/14) 为参照；上述补充保留已核对正确的主体公式。

4. 删除无数据、截断和误差范数支撑的NN/DD/DN收敛优劣及“更符合物理”等评价。
5. 删除“边缘buffer就可以忽略V2”的推断，替换为Cauchy–Schwarz界：

```text
|Eβ[V]−Eβ[V1]| ≤ Eβ[V2] + 2√(Eβ[V1]Eβ[V2])
```

若 `Eβ[V2]/Eβ[V1]≤ε²`，相对保留能量的误差才有 `2ε+ε²` 上界。

6. 删除无一般条件支撑的Gibbs误差“必然集中于边缘”等断言；有限展开的边缘恒等式不强加给只有H¹收敛的极限。
7. 合并符号表中的重复能量条目，删去重复的Green恒等式推演、单模态因子推导和总结清单。必要公式、证明及条件保留。

## 五、客观判断的边界

以下结论在本次核对中得到支持：声明的常用特殊函数恒等式、径向Neumann谱和归一化、有限模态体/表面能量块、NED梯度与Hessian、旋转约定以及闭壳通量；新补的能量完备性论证也逐步与所用二次型匹配。

仍不应作以下保证：所有高阶参数下的数值稳定性、所有无限展开均可逐项求导、任意边界数据均产生有限表面能量、所有边缘数据均有高阶正则性、有限含噪数据可以稳定区分物理源区，以及本文未证明的问题在整个学界均未解决。

**修订后的准确定位是：在明确边界、正则性、规范和收敛条件下组织的数学手册；不能将其标成“已经认证无任何错误或冗余”。** 此次报告和测试材料保留了核查依据，后续发现新问题仍可据此定位和修订。
