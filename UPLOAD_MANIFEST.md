# R-SCHA v2.0 distribution

Target public repository: https://github.com/ZhangPan-666/RSCHA-v2.0

Included: complete OpenMP/MPI source trees, SHRSCHA localization modules, mathematical foundations PDF and notes, historical acceptance summaries, table preparation/build scripts, and the 158,806,776-byte canonical-residual table.

`PACKAGE_SHA256SUMS.txt` lists SHA-256 hashes for all distribution files except itself. Build output and measurement/global-model datasets are excluded. The table is included once in `large_assets/`; preparation scripts copy it to each source tree after extraction.

The complete ZIP is intended as a GitHub Release attachment. It exceeds the ordinary per-file Git repository limit. Download the attached distribution ZIP rather than the automatically generated source-code archive.

See validation/BUILD_CHECKS_20261017.md for the local six-program compilation check and validation/VALIDATION_SUMMARY.md for numerical-validation scope. Reuse licenses have not yet been selected.
